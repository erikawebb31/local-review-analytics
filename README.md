# Local Review Analytics

A Next.js dashboard and typed API for local business rankings.

**Portfolio project:** Uses fictional sample data; not affiliated with BusinessRate or any employer.

## Run locally

```bash
npm install
npm run dev
```

## What to discuss in an interview

- Input validation and error handling
- TypeScript types and testable business logic
- How to evolve the prototype toward PostgreSQL, production authentication, and deployment
